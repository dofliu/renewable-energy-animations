# 視覺與文字規範

## 目錄
1. 色彩　2. 字型　3. 畫面配置　4. 動態　5. 分鏡寫法　6. 文字風格　7. 檢查清單

## 1. 色彩

頁面（style.css 已內建，支援深淺色模式）：背景 `#e7eeec`、表面 `#f6f9f8`、文字 `#13232e`、次要 `#4f6470`、海藍 `#1f7f99`。

畫布語意色，全系列一致，觀眾會學會它們的意思：

| 色 | 用途 |
|---|---|
| `#0e2a3b` 深海藍 | 圖解分鏡背景（`diagBG()`）、卡片底 `rgba(7,27,39,.75)` |
| `#f2c230` 訊號黃 | 重點、目前步驟、主要數值、標題色、`st:'s'` 標籤 |
| `#e8572a` 警示橘 | 風險、限制值、管制線、`st:'w'` 標籤 |
| `#7dffc4` 薄荷綠 | 量測資料、正常／通過、改善後的數值、`st:'g'` 標籤 |
| `#58b8d0` / `#7dc8dc` | 水、次要資料系列 |
| `#ff8a60` / `#ff9d7a` | 未改善的數值、高壓電 |
| 白與 `rgba(227,236,238,.8)` | 圖解內主要／次要文字 |

同一集不要引入新的強調色；需要第三種資料系列時用 `#b37cff`。

## 2. 字型

- 中文：Noto Sans TC（700–900 用於標題）。
- 數字、刻度、單位：Barlow Condensed（`COND`），讓數字有儀表感。
- 圖解內文字用 `wt()`，大小建議：卡片標題 20、內文 17–20、主數值 26–44。`wt()` 會自動保證手機上的最小字級。

## 3. 畫面配置（世界座標 1600×900）

```
┌──────────────────────────────────────────────┐
│ [章節卡 約 420×130，保持淨空]   [HUD 面板 右上] │
│                                              │
│              主要畫面內容                      │
│                                              │
│            [字幕 置中底部 約 y>820]            │
└──────────────────────────────────────────────┘
```

- 圖解分鏡常用兩欄：左 60–760、右 800–1540（或 900–1540），卡片頂端 y≈150–170、底端 ≤800。
- 有 HUD 的分鏡，右上角約 x>1250、y<320 不放重要內容。
- 側視場景：海平面 `SEA=470`，風機位置 `TX=640`，變電站 `OX=1120`，海岸 `COAST=1455`（kit-marine）；陸地地面 `GY=600`（kit-land）。
- 鏡頭用 `cam(u)` 回傳 `{x,y,s}`，`s` 在 0.95–3.2 之間；推近特寫用 `camMix(a,b,ease(seg(u,a0,a1)))`。

## 4. 動態

- 引擎已處理：片頭標題（前 3 秒）、分鏡間淡出淡入。不要另外加華麗轉場。
- 每個分鏡內只安排一條主線動作；次要元素（雲、浪、魚、氣泡）持續緩動營造「活著」的感覺。
- 標籤用 `band(u,a,b)` 控制出現區間，跟著字幕節奏出現、完成任務就淡出，同一時間畫面上的標籤不超過 4–5 個。
- 數值要會動：計數器、進度條、曲線逐步畫出，讓觀眾看見「過程」。

## 5. 分鏡寫法

每個分鏡回答一個問題。常見的深入手法：

- **剖面**：打開設備看內部（機艙、海纜、葉片、電池模組）。
- **原理圖**：公式＋動態示意（都卜勒頻移、升壓降損、氣泡幕減噪）。
- **圖表逐步生成**：量測曲線、分布、功率曲線、損失瀑布圖。
- **比較**：兩欄並列（灌漿式 vs 螺栓式、直驅 vs 齒輪箱），每欄 2–3 個優缺點。
- **風險**：畫出出錯的樣子（穿刺、淘刷、尾流），再畫解法。
- **流程**：橫向步驟方塊依序點亮（審查流程、送電順序）。

一集的典型結構：現場進場 → 原理圖解 → 關鍵施工或運轉 → 第二個原理或風險 → 成果或下一步。

## 6. 文字風格

- 繁體中文、台灣用語（「海纜」「變流器」「併網」「度」）。專有名詞第一次出現時括號附英文縮寫，例如「浮動式光達（FLS）」。
- 字幕：一句話、20–30 字、描述畫面正在發生的事。
- 說明段落 `d`：120–200 字，說清楚「在做什麼、為什麼、關鍵數字」，口吻像博物館導覽，不用驚嘆號與行銷語氣。
- 標籤：2–10 字的名詞片語。
- 重點數字：`[數值, 單位, 一句說明]`；推估或範例值在說明中註明「示例」。
- 不用表情符號、不用全大寫英文標籤。

## 8. 翻譯風格（英文／日文）

- 英文：標註與 HUD 用簡短名詞片語（Main crane、Pile sleeve），不用句號；字幕為一句完整但精簡的句子；說明段落用自然的科普英文，專有名詞用業界慣用語（monopile、transition piece、jack-up vessel、array cable、export cable）。英文通常比中文長 1.5–2 倍：畫面標註盡量 ≤ 4 個字，HUD 標籤 ≤ 3 個字。
- 日文：用日本業界用語（モノパイル、トランジションピース、洋上変電所、アレイケーブル、ジャッキアップ），字幕用「〜する」「〜を確認」等簡潔體，說明段落用です・ます體。數字與單位的全形／半形與中文版一致。
- 台灣特有名詞加上說明而非直譯（台灣白海豚 → Taiwanese humpback dolphin／タイワンシロイルカ）；度（kWh）與億、萬等單位在英文換成 GWh、TWh、thousand。
- 翻完一定看英文總覽圖，擠出框的標註改短寫法，而不是縮小字級。
